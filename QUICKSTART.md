# Quickstart: Pedestrian Detection (Low Light)

This short guide gets you from raw data to reproducible evaluation artifacts. For a
more detailed, step-by-step pipeline, see `pipeline.md`.

## 1) Prepare data

Generate YOLO labels and index splits from NightOwls COCO annotations:

```bash
python scripts/prepare_data/prepare_nightowls.py labels \
  --raw-ann data/raw/annotations \
  --raw-img data/raw/images
```

> Tip: `prepare_nightowls.py` supports custom annotation filenames via
> `--train-ann-file` and `--val-ann-file` if your JSONs live elsewhere.

## 2) Train (baseline)

Use Ultralytics YOLO directly (example):

```bash
yolo detect train data=configs/data.yaml model=yolov8n.pt imgsz=640 epochs=... device=0
```

Or use the provided runner:

```bash
python scripts/yolo_runs/run_yolo_baseline.py train \
  --data configs/data.yaml --imgsz 640 --epochs ... --batch ... --seed 42
```

The best checkpoint will be at `runs/train/<exp>/weights/best.pt`.

## 3) Create an eval run folder

This step creates an eval directory and baseline artifacts that the report step
expects (even though we’ll overwrite predictions later).

```bash
python scripts/yolo_runs/run_yolo_baseline.py test \
  --data configs/data.yaml \
  --model runs/train/<exp>/weights/best.pt \
  --imgsz 640 --conf 0.001 --iou 0.50 --max_det 300 --workers 8
```

## 4) Make COCO pixel-space predictions

Ultralytics evaluation uses letterboxed coordinates. For accurate COCO metrics,
use the pixel-space predictions generated by `predict_to_coco.py`.

```bash
python scripts/yolo_runs/predict_to_coco.py \
  --data configs/data.yaml \
  --gt data/raw/annotations/val/nightowls_validation.json \
  --model runs/train/<exp>/weights/best.pt \
  --split test \
  --imgsz 640 --conf 0.001 --iou 0.50 --max_det 300 \
  --outdir runs/predict/baseline_test
```

Replace the `predictions.json` inside your eval run folder with the file created
here (`runs/predict/baseline_test/predictions.json`).

## 5) Generate COCO tables + PR tensors

```bash
python scripts/yolo_runs/run_yolo_baseline.py report --split test
```

This writes `metrics_by_class_area.csv` and `pr_data.npz` into the eval folder.

## 6) Compute NightOwls MR-2 (Reasonable)

```bash
python scripts/metrics/missrate_nightowls.py \
  --gt data/raw/annotations/val/nightowls_validation.json \
  --pred runs/predict/baseline_test/predictions.json \
  --iou 0.5 --min_height 50
```

## 7) Enhancement variants (optional)

To evaluate Zero-DCE or other enhancement variants, generate the enhanced
dataset and repeat steps 3–6 using the enhanced YAML and predictions:

```bash
python scripts/enhance/enhance_dataset.py \
  --src-root data/raw/images \
  --dst-root data/enhanced/zerodce \
  --weights path/to/zerodce_weights.pth
```

Then use `configs/data_zerodce.yaml` and the corresponding index files.
